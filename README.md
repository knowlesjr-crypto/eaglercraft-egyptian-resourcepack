# eaglercraft-egyptian-resourcepack
An Egyptian-themed resource pack for Eaglercraft with hieroglyphics, sand textures, and ancient Egyptian aesthetics

## Generate the pack

```bash
python -m pip install -r requirements.txt
python generate_egyptian_pack.py
python build_zip.py
```

This creates a zip archive named `eaglercraft_egyptian_pack.zip` in the repo root.

## Load it in Eaglercraft

- Open the Eaglercraft resource-pack menu
- Add or import the zip file
- Select it as the active resource pack

## Included style

- warm desert sand tones
- sandstone and temple-brick textures
- gold accents
- Egyptian-inspired symbols and patterns
- turquoise water
